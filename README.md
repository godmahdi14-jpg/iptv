# پلی‌لیست شخصی IPTV (همیشه به‌روز)

این ریپازیتوری فقط کانال‌های موردنظر شما (۴۷۶ کانال) رو از پلی‌لیست بزرگ
[iptv-org](https://github.com/iptv-org/iptv) استخراج می‌کنه و هر روز به‌صورت
خودکار به‌روزرسانی می‌کنه، تا لینک‌های استریم همیشه تازه بمونن.

## فایل‌ها
- `channels.txt` — لیست شناسه‌ی (tvg-id) کانال‌های موردنظر شما
- `filter_playlist.py` — اسکریپتی که پلی‌لیست کامل iptv-org رو می‌گیره و فیلتر می‌کنه
- `playlist.m3u` — خروجی نهایی (هر روز خودکار آپدیت می‌شه)
- `.github/workflows/update.yml` — تنظیمات اجرای خودکار روزانه

## راه‌اندازی (فقط یک‌بار)

1. یک ریپازیتوری جدید و **عمومی (Public)** توی گیت‌هاب بسازید، مثلاً به اسم `my-iptv`.
2. همه‌ی فایل‌های این پوشه رو داخلش آپلود کنید (یا با گیت پوش کنید).
3. برید به تب **Settings > Actions > General** و مطمئن شید که
   "Workflow permissions" روی **Read and write permissions** تنظیم شده
   (این اجازه رو می‌ده که اکشن بتونه فایل `playlist.m3u` رو خودش کامیت کنه).
4. برید به تب **Actions**، روی workflow به اسم **Update IPTV Playlist** کلیک کنید
   و دکمه‌ی **Run workflow** رو بزنید تا یک‌بار دستی اجرا بشه و فایل `playlist.m3u` ساخته بشه.
5. از این به بعد، هر روز ساعت ۳ صبح (UTC) خودش اجرا می‌شه و فایل رو تازه می‌کنه.
   (زمانش رو می‌تونید توی `.github/workflows/update.yml` با تغییر مقدار `cron` عوض کنید)

## گرفتن لینک همیشه‌ثابت پلی‌لیست

بعد از این‌که workflow حداقل یک‌بار اجرا شد و فایل `playlist.m3u` توی ریپو ساخته شد،
لینک خامِ (raw) فایل رو از گیت‌هاب بردارید:

```
https://raw.githubusercontent.com/USERNAME/REPO_NAME/main/playlist.m3u
```

(به‌جای `USERNAME` و `REPO_NAME` نام کاربری و اسم ریپوی خودتون رو بذارید)

همین لینک رو داخل اپ IPTV خودتون (VLC، TiviMate، IPTV Smarters و...) به‌عنوان
آدرس پلی‌لیست وارد کنید. از این به بعد هر بار که اپ رفرش کنه، آخرین نسخه‌ی
فیلترشده و به‌روز رو می‌گیره — بدون این‌که خودتون کاری کنید.

## اگه بعضی کانال‌ها بعد از فیلتر پیدا نشدن

اسکریپت در پایان اجرا، لیست کانال‌هایی که توی منبع اصلی iptv-org پیدا نشدن رو
چاپ می‌کنه (این لاگ رو می‌تونید توی تب Actions هر اجرا ببینید). دلیلش معمولاً
یکی از این‌هاست:
- اون کانال از پلی‌لیست iptv-org حذف شده
- شناسه‌ی (tvg-id) کانال توی دیتابیس اونا تغییر کرده

در این حالت باید `channels.txt` رو دستی به‌روز کنید.

## اضافه یا حذف کردن کانال

فقط کافیه tvg-id مربوطه رو به فایل `channels.txt` اضافه یا ازش حذف کنید و
دوباره workflow رو (دستی یا با صبر کردن تا اجرای بعدی) اجرا کنید.
